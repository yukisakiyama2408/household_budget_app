## 機能の所属

主要ナビゲーションは「ホーム・収支・予算・分析」の4項目。設定は補助メニュー、登録は共通アクションとする。PC・スマホで名称と所属を共通にする。

| 所属 | 役割 | 管理する機能 |
| --- | --- | --- |
| ホーム | 現在の状態と次に必要な操作を知る | 残高、予算消化、最近の取引、目標の要約、未登録・要確認の案内 |
| 収支 | 実際のお金の動きを記録・修正する | 取引明細、手入力、CSV取り込み、固定費、クレジット引落額 |
| 予算 | これから使うお金と目標を決める | 月次・週次予算、AIによる予算見直し、貯蓄・支出上限の目標 |
| 分析 | 実績を集計し振り返る | 日・週・月・年の集計、推移、分析記録、AI分析、週次チェックイン |
| 設定 | アプリ共通の管理をする | カテゴリ、通知、アカウント、改善要望 |

- ホームの詳細リンクは担当画面へつなぐ。管理フォームの複製は置かない。
- 収支の画面切り替えは「取引明細／固定費／カード引落」とする。
- 予算の画面切り替えは「予算／目標」とする。予算と貯蓄目標の計算・入力は分ける。
- 分析の画面切り替えは「集計・推移／振り返り」とする。週次チェックインは振り返り配下の操作とする。
- AIは独立した主要メニューにせず、分析する操作は分析、予算を作る操作は予算に置く。
- 日次・週次・月次・年次は集計単位として切り替える。

## 旧URLの移行先

移行先を実装してから旧URLの転送を切り替える。未実装ページへの転送は先行して追加しない。

| 現在のURL | 移行先・変換 |
| --- | --- |
| `/transactions`、`/transactions/new`、`/transactions/[id]/edit` | 維持 |
| `/import` | `/transactions/import` |
| `/fixed` | `/transactions/fixed` |
| `/fixed/new` | `/transactions/fixed/new` |
| `/fixed/[id]/edit` | 同じIDの `/transactions/fixed/[id]/edit` |
| `/budget`、`/budget?tab=budget` | `/budget`。期間を変換・維持 |
| `/budget?tab=fixed` | `/transactions/fixed`。選択月を維持 |
| `/budget?tab=categories` | `/settings/categories` |
| `/goals`、`/goals/manage` | `/budget/goals` |
| `/monthly`、`/monthly?tab=stats` | `/analysis`。集計単位・期間を維持 |
| `/monthly?tab=insights`、`/insights` | `/analysis/reviews`。分析単位・期間を維持 |
| `/daily?month=YYYY-MM` | `/analysis?view=daily&period=YYYY-MM` |
| `/daily?year=YYYY` | 現在のページの選択月に相当する日次表示へ。過去年は1月、当年は日本時間の当月 |
| `/yearly?year=YYYY` | `/analysis?view=yearly&period=YYYY` |
| `/checkin` | `/analysis/reviews/checkin`。週未指定なら今週 |
| `/settings` | 維持。固定費の管理フォームは収支へのリンクに置き換える |
| `/feature-requests` | `/settings/feedback` |

- 期間未指定の旧URLは移行先の既定期間を使う。`tab`など不要になった互換パラメーターは転送先から除く。
- 現在の `next.config.ts` には `/fixed → /budget?tab=fixed`、`/insights → /monthly?tab=insights`、`/checkin → /` の永続転送がある。移行先実装時に置き換え、転送の循環・不要な多段転送を避ける。

- 旧ページは設定だけでなく、内部リンク・保存後の戻り先・`revalidatePath`・cronの再検証先を更新した後に整理する。
- `/login`、認証処理、`/api/*`、PWA関連のURLは今回の再編対象外。

## 期間と絞り込みのルール

### 予算・分析

`view` と `period` を共通の表現とする。

| 集計単位 | `view` | `period` | 対応画面 |
| --- | --- | --- | --- |
| 月 | `monthly` | `YYYY-MM` | 予算・集計・振り返り |
| 週 | `weekly` | 月曜日の `YYYY-MM-DD` | 予算・集計・振り返り・チェックイン |
| 年 | `yearly` | `YYYY` | 集計・振り返り |
| 日別の月間一覧 | `daily` | `YYYY-MM` | 集計 |

- 例：`/budget?view=monthly&period=2026-10`、`/analysis/reviews?view=weekly&period=2026-10-26`。
- 週は月曜〜日曜の7日間。月をまたぐ週も1つの週として指定し、予算の月別期間への分割計算は維持する。
- 月内の週選択に必要な表示対象月は、週次予算のみ `month=YYYY-MM` を追加できる。期間は `period` で決定する。
- 例：`/budget?view=weekly&period=2026-10-26&month=2026-11` は11月の週選択で10月26日開始の週を表示する。`month` がなければ週開始日の月を使う。
- 現在の予算の `year`・`month`・`weekStart` は移行時に変換する。正しい新形式が指定されていれば新形式を優先する。
- 現在の分析URLの `view`・`period` を優先し、旧形式の `month`・`year`・`week` だけの場合は形式を検証して変換する。
- 日付は日本時間を基準にする。過去期間を選択可能とし、データがない正しい期間は空状態を表示する。
- 既定値は予算・分析とも当月、週表示は今週、年表示は当年。無効な値は画面ごとの既定値に戻す。
- 単位切り替えでは選択期間の基準日を維持する。基準日は月・年なら初日、週なら月曜日。日別表示はその基準日が属する月を表示する。
- 「今月に戻る」「今週に戻る」は明示的な操作として用意する。

### 収支・固定費・カード引落

- 取引明細の既存の `month=YYYY-MM`・`month=all` は維持する。
- 取引明細は月未指定を既定とし、全期間を対象に最新50件から表示する。「もっと読み込む」で50件ずつ続きを取得する。
- 月・収支区分・カテゴリ・支払方法・確認項目は複数選択できる。同じ項目内はOR、項目間はAND。URLは同じキーの繰り返しで保持し、単一値の既存リンクも利用できる。
- 絞り込みは選択・解除のたびに自動適用する。検索は日本語変換の確定後、入力が350ms落ち着いた時点で適用する。条件変更時は先頭50件から再表示する。収支一覧の金額は「表示中」の明細合計と明示し、追加読み込みに合わせて更新する。
- 週・年から明細へ移動するときは `dateFrom=YYYY-MM-DD`・`dateTo=YYYY-MM-DD` を使う。開始日・終了日を含む。
- 有効な開始日・終了日の組があれば `month` より優先する。片方のみ・逆順・不正な日付の範囲は採用せず、有効な月指定、なければ全期間を使う。
- カテゴリの引き継ぎは名前ではなく既存の `category_id` を使う。検索・種別・支払い方法など既存の絞り込みも維持する。
- 固定費の反映月・カード引落の表示対象月は `month=YYYY-MM`。引落の実際の日付は別の入力値として扱う。
- カード利用明細と引落額の役割を区別し、残高・支出集計の計算は移動前の仕様を維持する。

### 移動と編集後の戻り先

- ホームの各リンクは、カードで表示している期間を渡す。
- 予算・分析・明細間では同じ対象期間を渡す。無関係な検索条件は他の機能へ持ち込まない。
- 同じ機能内の移動・編集後は期間・絞り込みを維持する。目標など期間を使わない画面を経由して戻る際も、直前の期間に戻れるようにする。
- 登録・編集の `returnTo` は、アプリ内の許可した担当一覧URLに限定する。未指定・不正なら担当一覧へ戻す。外部URLは受け付けない。
- 例：`/transactions/fixed/new?returnTo=%2Ftransactions%2Ffixed%3Fmonth%3D2026-10`。
- 新規取引の日付は通常は日本時間の今日。過去の明細から登録しても、選択月の初日を自動登録日にはしない。
- URLを再読み込み・共有したときも同じ表示になり、ブラウザの戻る・進むで状態を復元できるようにする。

### ステップ5の実装

- 集計は `/analysis`、振り返りは `/analysis/reviews`、週次チェックインは `/analysis/reviews/checkin` に集約する。ナビと予算の分析リンクも正式URLへ更新する。

- 旧 `/monthly`・`/daily`・`/yearly`・`/insights`・`/checkin` は有効な期間を変換して一時転送する。旧設定の `/insights`・`/checkin` の永続転送を取り除く。
- 取引・固定費反映・カード引落・カテゴリの更新と、分析記録・チェックインの保存後の再検証先を新画面へ変更する。
- 日本時間、うるう年、データのない過去期間、月・年跨ぎ、集計単位の切り替え、旧URL転送を自動テストで確認する。認証済みブラウザでの表示・本番データ更新は別途確認する。
